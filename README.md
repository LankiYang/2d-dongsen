# 2D动森

多人联机网页游戏：**2D 版的《动物森友会》**。大家共用一座港口小镇（潮汐港，7 位村民和他们的故事），每人另有一座自己的小岛；游戏时间跟现实同步，每天上线在岛上转一圈：摇树、敲石头、捡贝壳、钓鱼抓虫、做家具、布置小岛、去朋友岛上串门。世界持久运行。

> **项目来历**：2026-10-07 从「潮汐港 Tidehaven」（潜水员戴夫 × 星露谷，仓库 LankiYang/tidehaven）独立出来，起点是潮汐港仓库 `animal-crossing` 分支的 1faee4d。两个项目从此各自发展、互不影响：这边的改动不要回写到潮汐港。规划和进度见 [`docs/plan.md`](docs/plan.md)。
>
> 下面「当前可玩内容」里还留着不少潮汐港时期的玩法（格子农田、鱼枪潜水、鲨鱼、寿司店、体力、复兴工程），正按规划一块块改成动森式的，改到哪一块就更新哪一块。

> **美术是这个项目的第一优先级。** 任何改动如果让画面变差（色调不统一、特效糊掉、新旧画风混搭），都不值得。
>
> 陆地场景是高清平滑画风（见 `docs/plan.md`「画面：高清平滑画风」），下面讲 PixelView、像素化还原、整数缩放的段落只适用于海底和 `?oldstyle`（潮汐港时期的旧画面，对照用）。

## 已锁定的决策（用户明确选定，不要自行更改）

| 补充素材 | 网上找**免费可商用**素材，补 AI 不擅长的部分（字体、音效、音乐）。下载前要列清单给用户确认 |
| 项目 | **和潮汐港完全独立**（2026-10-07 用户定）：单独的文件夹、仓库（LankiYang/2d-dongsen，公开）、端口和存档，不影响潮汐港 |
| 世界结构 | **完全照动森**（2026-10-07 用户定）：每人一座岛就是全部（机场、岛务所、商店、博物馆、村民都在自己岛上），坐飞机去朋友的岛和无人小岛；不再有共用小镇 |

| 村民 | 搬到岛上的伙伴是**动物村民**（8 种性格，2026-10-07 用户定）；潮汐港的 7 位人类角色改当岛上设施的工作人员（周叔、阿海、豆豆、老潘、小珊、花婶、阿澜） |

| 时间 | 跟现实时间同步（北京时间），季节按现实月份 |
| 玩法 | **完整还原动森**（2026-10-07 用户定，原作的流程和数值见 `docs/acnh-research.md`，开局是机场 → 移居到岛上 → 序章引导）。每日采集、工具和 DIY、钓鱼抓虫、图鉴和博物馆、装修小岛、互相串门。**去掉体力**；潜水改成动森式（徒手抓海洋生物进图鉴，去掉鱼枪和鲨鱼）；**去掉寿司店做菜**。先做私人小岛 + 每日采集，美术重画先停，玩法做出来再补画 |

## 运行

```bash
git lfs install        # 仓库里的图片/音频/字体走 Git LFS，克隆前需要装好
npm install
cp .env.example .env   # 只有重新生图时需要：填入 CLOUDSWAY_API_KEY
npm run server        # 游戏服务端 :8799（WebSocket /ws + 生产环境托管 dist/）
npm run dev           # 客户端开发服务器 :5192（/ws 代理到 8799）
npm run build         # 打包到 dist/，之后只开 server 即可：http://localhost:8799
npm run typecheck
node tools/bot.mjs 3 60   # 联机冒烟测试：3 个机器人住进村子，在自家门口附近绕圈、聊天
```

操作：WASD 移动 · 鼠标左键/空格 使用手上物品 · 1-8 切换 · 滚轮或 +/- 缩放镜头（每个场景各自记住） · E 互动（和 NPC 说话 / 出货箱 / 回船 / 进出寿司店 / 做菜 / 上菜）· 对话和菜单里按数字键选 · Q 倒掉手上的菜 · I 背包 · J 任务栏（任务 / 关系） · Enter 聊天

## 当前可玩内容

- **标题画面**：背景就是游戏里的岛（`src/island/title.ts`，岛屿场景的展示模式：不显示玩家、不接输入、不连服务器），镜头按分镜慢慢推：田地 → 潮汐村 → 集市 → 码头 → 寿司店 → 灯塔，一天从早上走到深夜，镜头之间淡出淡入，上下电影黑边，底部字幕讲每个地方能做什么。复兴工程按全部完工的样子摆（客船、亮着的灯塔），田里种一片演示用的庄稼；登录后换成服务器上的真实状态。左边是标题和「登岛」卡片（名字、衬衫颜色，角色站在一小块草地上原地走、转身）；第一次点击或按键后放出音乐和海浪声
- **手机 / 平板**（触屏设备自动打开，`src/ui/touch.ts`；电脑上网址加 `?touch` 可以强制打开来调试）：左下角浮动摇杆（手指按在左下区域哪里就从哪里推）；右下角「互动」键（= E，按钮上写着当前能做的事，比如「和阿海说话」，没得互动时变灰；底部提示条也能点）和「使用」键（= 空格，水下变成「射击」，屋里不显示）；左上角背包、任务、聊天、全屏（安卓上全屏会顺便锁横屏）。点屏幕：岛上点够得着的地块就对它用工具，水下点哪里就朝哪里射；手指松开后改用面朝的方向（摇杆推向哪里就瞄哪里）。双指捏合缩放。小屋里多一个「目录」键、拿着家具时多一个「翻转」键，寿司店端着菜时多一个「丢掉」键。背包点一格再点另一格就交换，商店里点一下卖 1 个、长按全部卖出。面板在矮屏幕上缩小、太长就滚动；竖着拿手机会提示横过来。加到主屏幕可以全屏运行
- **岛屿**（3/4 俯视）：锄地 → 播种 → 浇水 → 每天早上 6:00（现实时间）按浇水情况生长 → 收获，作物要长 2～5 天；5 种作物各 4 个生长阶段；下雨时田地自动浇透
- **海底**（侧视）：在栈桥尽头找船长老潘出海，侧视潜水船停在海面上；三个深度区（珊瑚浅滩 / 蓝色断层 / 蓝洞深处）；23 种可捕鱼 + 海龟鲨鱼等氛围生物；鱼枪射击、按鱼的血量多次命中（每条鱼至少两枪，挨一枪就加速逃走，大鱼血厚要好鱼枪）；腰上的**鱼篓**装满了（初始 8 条）打死的鱼会逃掉，得回船上卸货；氧气耗尽会丢掉这次潜水抓的鱼；被捞空的海域要过一阵才会重新热闹起来。出海要花**体力**（见下）。**鲨鱼是敌人**：断层有 2 条礁鲨、蓝洞有 2 条大青鲨（服务端模拟，全服同一批），平时巡游，发现 230 / 280 像素内的潜水员就追过来（追人速度 100 / 112，潜水员最快 120）（头顶闪红色感叹号），咬到一口扣 25 / 40 秒氧气并把人撞开，之后 2.5 秒无敌、鲨鱼游开一阵；用鱼枪打中能把它吓跑。鲨鱼不会离开自己的海域，浅滩是安全区。远景里只游海龟和小鲨鱼，而且只刷在海面以下
- **潮汐村**：岛南边一座有机布局的村子——广场居中（井、公告栏），村道呈放射状弯出去，10 栋房子分布在高低错落的台地上，南排中间留一片小树林。房子固定建好，样式按宅基地固定（4 种，全是正立面朝向镜头），新玩家上线自动搬进一栋空房、从自家门口出发。每户按「性格」手摆院子（渔家晒鱼、花园人家围白栅栏种花、农家养鸡种菜、海边高脚屋摆冲浪板和躺椅），名牌挂在信箱上（自己的插小红旗），没人住的挂「空房」、夜里不亮灯
- **小屋**：走到有人住的房子门口按 E 进屋（自己的是「回家」，别人的是「拜访」，房主会收到提示）。四种房子对应四种室内（原木板墙 / 白灰泥墙配蓝护墙板 / 浅色木板 / 石砖墙深色地板），新房自带床、床头柜、桌椅、地毯、储物箱、窗户、画、盆栽、门垫。房主在屋里按 C 打开**家具目录**（31 件：落地家具、地毯、墙饰），买来的家具进背包；拿在手上会有半透明预览跟着鼠标（放不下变红），左键摆放、R 翻转；对着家具按 E 收回背包。**储物箱** 24 格，东西存在服务端（按 E 打开，Shift+E 收起空箱子）。访客能看不能动，房主摆放时屋里的人实时看到
- **体力**：上限 100（时钟下面的绿条），每分钟回 1 点、一百分钟回满；出海一次花 40。作物拿在手上「使用」就吃掉回体力（稻米 +10、黄瓜 / 番茄 +15、草莓 +25、南瓜 +40），等不及就拿收成去换
- **潜水装备升级**（找小珊）：鱼篓、气瓶、鱼枪各 4 级，装备不占背包格，升级后下次下潜生效。高级装备除了金币还要上一片海域的鱼当材料，形成「浅滩 → 断层 → 蓝洞」的成长线：
  - 鱼篓：小竹篓（8 条）→ 大竹篓（12 条，400 金）→ 网兜鱼篓（18 条，1500 金 + 5 条鲭鱼）→ 潜水员背篓（24 条，4000 金 + 3 条章鱼）
  - 气瓶：标准（150 秒）→ 大容量（210 秒，600 金）→ **高压**（270 秒，2000 金 + 3 条真鲷，**解锁蓝洞深处**）→ 双联（360 秒、深处几乎不额外耗氧，5200 金 + 2 条石斑鱼）
  - 鱼枪：竹柄（伤害 1 / 射程 150）→ 钢芯（射程 185、上弦更快，500 金）→ 气动（伤害 2 / 射程 215，1600 金 + 3 条黑鲷）→ 潘家祖传（伤害 3 / 射程 245，4800 金 + 2 条鰤鱼）
  - 没有高压气瓶时，下到约 30 米（`PRESSURE_LIMIT_Y`）会被水压像弹簧一样托回去，深度计变红闪烁、提示去找小珊；服务端同样按气瓶等级限制深度、按鱼枪等级结算伤害和射程
- **村民**（带双表情立绘的对话框、各自的说话音高）：阿海（鱼摊）、花婶（种子铺）、老潘（船长）、小珊（潜水教练）、周叔（村长）、阿澜（寿司师傅）、豆豆（花婶的孙子）。人物设定和剧情大纲在 `docs/story.md`。在岗位附近闲逛，玩家靠近会停下转身
- **好感度**（照星露谷的规则，每位玩家和每位村民各自一条）：0~10 心，每心 250 点。每天第一次聊天 +20；送礼（拿在手上跟对方说话，选「送出」）按喜好 最爱 +80 / 喜欢 +45 / 一般 +20 / 不喜欢 -20 / 讨厌 -40，每人每天 1 份、每周 2 份，生日当天 ×8；完成对方的委托 +150。台词按心数分五档，关系越好说得越私人、越多透露过去；收礼、交付委托都有专门的反应台词。每到 2、4、6、8、10 心都会寄来一封信和礼物
- **任务**：J 打开任务栏（任务列表 + 关系页：心数、今天聊没聊、本周送礼次数、生日），时钟下面有任务追踪条。新手主线「认识大家」（和 7 位村民都打声招呼，奖励 150 金币）。同时进行一条**新手引导**（`shared/quests.ts` 的 `GUIDE`，做完一步自动接下一步，每步有金币、好感，有的带种子）：花婶教种地（种 6 颗）→ 浇水（6 块）→ 老潘带你出海（抓 3 条鱼）→ 阿海教卖货（卖 3 样，顺便告诉你鱼直接卖不值钱）→ 豆豆要礼物（送 1 份）→ 阿澜教做寿司（上 1 道菜）→ 花婶教收获（收 3 个）→ 花婶教吃东西回体力（吃 1 个）→ 周叔教接委托（完成 1 张）→ 周叔带你看复兴工程（捐 1 次）→ 小珊教升级装备（升 1 次），走完一遍七位村民也就都见过了，最后周叔寄一封「往后的日子」。复兴工程已经全部完工、装备已经满级的，对应那一步自动跳过；下雨天浇水也算数。**任务指路**：屏幕边上的金色箭头指向当前该去的地方（先指东西已经凑齐、马上能交的委托，再指新手引导这一步，再指「认识大家」里离得最近、还没打过招呼的人），写着是谁、还有几格；目标进了画面就变成它头顶上一跳一跳的小箭头，走到跟前就消失。广场东北角的**告示板**每人每天一张委托（按玩家和日期确定性生成：送指定的鱼或作物，奖励卖价 ×3 + 委托人好感 +150，期限 2 天），能交付时委托人头上亮「！」
- **心事件**（过场剧情）：7 位村民各有 2、4、6、8、10 心五段，共 35 段（剧本在 `shared/events.ts`，设定在 `docs/story.md`）。好感够了、时段和天气对、走进指定地点就开演：镜头移动、角色走位、表情气泡（！？♥…）、旁白、淡入淡出、烟花和海里的荧光、对话和选项；选项影响好感，有的事件会给东西、开任务（阿海 6 心托你把真鲷「顺路」带给花婶，花婶收到时有专门的台词）。8、10 心的剧情和主线绑在一起：老潘 8 心请你去珊瑚浅滩找秀兰的铜怀表、阿海 8 心请你去蓝洞最底下找他的旧潜水刀（接了任务，海底对应的地方会闪光，游过去按 E 捡起来，再交给他们）；老潘 10 心要等灯塔修好、还回怀表以后才有；阿澜 8 心要等栈桥修好，一起去灯塔；花婶、豆豆、周叔的 10 心要等客船来了。剧情物品不能卖、不能送礼。每个游戏日最多演一段心事件；演的时候按 Esc 只会跳过一句，不会卡住
- **主线「潮汐港复兴计划」**（全服合作）：码头入口南边沙滩上的**复兴工程告示板**（按 E 打开）列出当前这期要的金币、鱼和作物，谁都可以捐，每项有进度条，右边是贡献榜（金币每 10 枚 1 分、物品按卖价算）。凑齐一期，第二天一早完工，全服聊天通知；玩家下次走到告示板附近会看一段**全镇剧情**（晚来的玩家只看最新的一段）。四期依次是：
  1. **修复栈桥**：通往东北角灯塔小岛的木栈桥修好，可以走上小岛
  2. **重建灯塔**：灯塔换成修好的样子，夜里光束转圈扫过海面和码头，灯室亮着
  3. **重开潮汐集市**：广场北边那片空地上的野树清掉，摆上四个摊位；每周六是**集市日**，在摊位前按 E 摆摊，卖价 +25%，花婶、周叔、豆豆白天会去集市
  4. **迎来客船**：客船「潮汐号」停在栈桥北边，寿司店的客人来得更勤；当晚办潮汐节（烟花）
  第一次上线（或更新后第一次上线）周叔会寄一封介绍信
- **村民日程**：每人按钟点在岛上两三个地方之间走动（阿海白天看鱼摊、傍晚去码头看海；花婶傍晚去广场唠嗑；小珊傍晚去沙滩练憋气；周叔中午去种子铺串门、下午去码头；豆豆中午去西边海滩捡贝壳……），下雨天有的人会换地方。走路用 A* 寻路绕开房子和树；赶路时不会因为玩家路过停下，只有正在和你说话时才站住
- **信箱**：自家门口的信箱，有新信时上方飘一个小信封；来信有欢迎信、复兴计划的介绍信、村民按心数寄来的信，附件（物品/金币）点「收下」
- **时间和历法**（本分支）：游戏时间就是现实时间（北京时间），每天早上 6 点换日；时钟显示现实的月、日、星期，季节按月份（3～5 月春……）。村民生日是现实日期（「夏 9 日」= 6 月 9 日），集市是现实的周六。大约三成的日子会下一阵雨（2～6 个钟点），换日时会在聊天栏预告。服务端的 `--start-hour` 只用于测试：把这次运行的「现在」挪到今天几点
- **潮汐寿司**（全服共用一家店）：鱼摊东边、栈桥入口旁的寿司店，每天 10:00–22:00 营业，一天最多来 24 位客人（全服共享，客船停靠后 36 位）。店里有人时客人陆续进门、坐到吧台前点菜（头顶气泡显示菜品和耐心条），打烊或等太久会离开。走到砧板/油锅前按 E 选菜（有人点的排在最前、标出几位在等），再玩「切三刀」时机小游戏定品质（一般 ×0.8 / 不错 ×1 / 完美 ×1.25）；端着菜隔着吧台对准客人按 E 上菜，等得越短小费越多（最多 30%）。8 道菜：刺身、握寿司、黄瓜卷、海鲜盖饭、南瓜天妇罗、草莓大福、番茄冷盘、金枪鱼大腹。**菜价 = 手艺费 + 所用食材卖价之和 × 系数**，最差品质也比直接卖原料赚，用的鱼越好菜越值钱；任意鱼的菜自动挑背包里最便宜的鱼。多人可以同时在店里分头做菜、互相看得到对方端着什么
- **经济**（数值依据见 `docs/economy.md`）：花婶那里买种子；阿海、花婶、出货箱都能卖货；寿司店把鱼和作物加工成更值钱的菜（菜价 = 手艺费 + 食材价 × 系数：一条小丑鱼直接卖 6，做成刺身 54；金枪鱼卖 150，做成大腹 390）。鱼主要是材料，钱主要从寿司店来；潜水的收入被鱼篓、体力、鱼群恢复速度、鱼的血量管着，不会无限刷
- **联机**：玩家互相可见（名牌、换色衬衫、挥工具动画、潜水手电）、聊天、农田和鱼群全服共享
- **世界**：昼夜跟着现实时间走，昼夜光照（窗户和路灯夜里亮起、萤火虫）、云影、下雨；农田四周是木篱笆，留三个门

## 美术管线（`tools/`）

```
jobs/*.json ──gen.cjs──▶ art/raw/*.png ──build-art.cjs（内含 pixelize）──▶ public/assets/<图集>.png/.json
                 ▲                              ▲
          tools/style.cjs（美术圣经）      art/manifest.json（切块命名/缩放）
```

1. **风格定调图**（`art/raw/key_*.png`）先画出目标画面，后续所有素材都把它当参考图喂给模型，锚定色调和笔触。
2. **按"家族"成批生成素材表**（一张图里画 8 种鱼、18 个道具……）：同一张图里的素材像素密度和相对大小天然一致。
3. **像素化还原**（`pixelize.cjs`）：AI 图是 1408×768 的"伪像素画"，工具从边缘分布估出像素网格的周期和相位，每格取众数色，得到真正 1:1 的像素图，再从四周 flood-fill 抠白底。
4. **切块与命名**（`build-art.cjs`）：连通块按"行优先"排序后按清单命名；数量对不上会报错并输出编号预览 `art/preview/<图集>__<原图>.png`。用 `node tools/atlas-preview.cjs <图集>` 按名字顺序核对。
5. **统一密度**：全游戏基准是"240 格宽"档；480 档的素材表用 `scale: 0.5` 众数缩小，缩小后自动补一圈同色相深色描边（`reoutline`），保住轮廓。

**关键经验（踩过的坑）**
- 模型只在 **120 / 240 / 480 格宽** 三档像素密度之间切换（周期 11.73 / 5.86 / 2.93 像素）。prompt 里写"LOW RESOLUTION，总共只有 48 像素高"能把它推到 120 档；物体的格数 ≈ 它在画布里的占比 × 档位。
- 生长阶段、动作帧这类"一排 N 个"的图，模型经常多画一个或把相邻两个粘在一起：切块时 `gap: 1`、用 `null` 丢弃多余块、用 `pick` 选取。
- 生图接口会被上游限流（`rate_limit`），`gen.cjs` 已内置退避重试，并发 3。
- 抠图依赖纯白背景，风格常量里的 `WHITE_BG` 不要删。
- **被围住的白底抠不掉**：flood-fill 只能从四周进去，凳子腿之间、栏杆缝、叶子缝里的白底会留下来。在清单条目里用 `holes: ["名字", …]` 点名这些精灵，`build-art` 会把它们身上近纯白（RGB 和 ≥ 735 且每个通道 ≥ 235）的像素清成透明。画出来的白色（米饭、白漆、白衣服）一般带灰或色偏，达不到这个阈值，但仍然只对点名的精灵做，别全局开
- **模型画侧面行走帧时朝向经常前后不一**：常见的是前两帧朝右、后两帧朝左，腿也经常几乎不动。现在的做法是单独生成一排侧面帧（prompt 逐帧写明触地/交错步态），清单里开 `alignFacing: true`，以第一帧为准比较上半身，自动翻转朝向相反的帧；代码里按"侧面帧朝右"处理。模型还常常多画一排背影，用 `pick: [0,1,2,3]` 只取第一排。
- 给已有设计的角色补行走帧：同时给两张参考图——农夫行走帧锁定尺寸和排版，角色设计图锁定造型。只给设计图的话，模型会换一档像素密度画。
- 侧面帧总比正面画得高 10%~20%，清单里用 `fitH` 把整组等比缩放到和正面一样高。
- 立绘用"同一角色两个表情并排"一次生成，两张之间的一致性远好于分两次生成。
- **建筑必须是正立面**（和俯视地面的透视一致）：prompt 写明"像星露谷那样的正面视图、立面平行于画面底边、看不到侧墙、屋顶从略高处看到顶面"，并给一张正面房子当参考图。要求"画小一点、只占画面一半"会被模型无视，它总是画满画布（480 档约 370 格宽），所以建筑统一用 `scale: 0.4`。
- 参考图会强烈带偏造型：用茅草屋当参考生成花婶家，得到的还是茅草屋。想要不同造型就换一张风格不同的参考图。

尺度基准：地块 24 像素，农夫 34 像素高，NPC 34~37 像素高，房子约 150×92（6 个地块宽），立绘约 100×110（对话框里放大 2~3 倍）。岛屿场景约 300 美术像素高（1080p 下放大 4 倍），海底约 360（放大 3 倍）。

**不是所有东西都该让 AI 画**：篱笆和白栅栏（`src/island/fence.ts`）、耕地、栈桥、门牌（`nameSign`）需要无缝拼接、自动连接或者显示动态文字，都是用和 AI 素材同一套调色板程序绘制的。

**改地图布局用离线预览**：`node --disable-warning=ExperimentalWarning tools/map-preview.mjs [x0 y0 x1 y1]` 按真实精灵尺寸把岛画成 `art/preview/map_*.png`，并列出冲突（物件压在路上、互相重叠、落进水里、门前没路）。调 `shared/island.ts` 里的 `LOTS` / `ROADS` / 院子摆设时反复跑它，零冲突后再进游戏看。

## 渲染架构（`src/`）

- **PixelView**（`core/pixelview.ts`）：世界先渲染进一张美术像素分辨率的 RenderTexture（最近邻），再整数倍放大到屏幕。摄像机小数部分用放大后精灵的偏移补，滚动平滑且像素不抖。
- **光照**：光源精灵加法混合渲染进半分辨率、线性过滤的光照图，`PostFilter`（`fx/post.ts`）在屏幕分辨率合成：`像素画 × (环境光 + 光照图)`。所以像素画锐利、光影过渡平滑，这就是潜水员戴夫的观感。
- **动画不能用连续变形**：在美术像素分辨率下，斜切、旋转、缩放会让每一行像素在不同时刻各跳一格，看起来像一条跳变线从上往下刷。植物摆动改成 `fx/sway.ts` 的做法：把精灵拆成上下两段，上段整块按整数像素平移（带回差，不会来回闪）；呼吸、弹跳、挥工具下沉一律用整数像素位移。只有鱼的网格游动和潜水员倾斜保留了连续变形（运动本身就在变形，看不出问题）。
- **缩放**：`PixelView.zoomBy` 按整数倍率缩放（缩小时视野不会超出地图），保证像素始终锐利。
- **碰撞**：水、房子、篱笆按地块阻挡；小物件（信箱、花坛、树干……）按 `shared/island.ts` 里 `SOLID_SIZE` 的像素底座阻挡，并用 48 像素分桶加速查询。移动时蹭到拐角会自动沿垂直方向错开几个像素（`slide`）；万一站进障碍物里（比如地图改版后的旧存档位置），`unstick` 会把人挪到最近的空地。以前小物件按整格阻挡，院子里会出现看不见的墙把人卡住。
- **NPC 与对话**：`shared/npcs.ts`（前后端共用）定义村民的生日、礼物喜好、按心数分档的台词和收礼反应，`shared/quests.ts` 定义每日委托和信件，`shared/schedules.ts` 定义日程（服务端也用它判断「玩家是不是在这位村民身边」，所以村民走到哪都能说话、送礼、交付），`shared/events.ts` 定义心事件（客户端 `island/cutscene.ts` 播放；服务端只校验好感门槛、前置事件、没看过，再执行选项效果），`island/npcs.ts` 只放情境台词、小贴士和对话选项（开头带 `^` 的台词用开心表情）；对话框是 DOM（`hud.dialog`），同一时间只保留一个按键监听，换人说话时必须摘掉旧的，否则数字键会触发上一段对话的选项。
- **室内**（`interior/`）：`room.ts` 是室内场景基类（烘焙地板墙面、固定摆设、走动碰撞、镜头、其他玩家、出门），`restaurant.ts`（寿司店）和 `home.ts`（小屋）各自只写互动。房间定义在 `shared/rooms.ts`（前后端共用：尺寸、门、家具摆放、碰撞底座、灶台、座位；`homeRoom(lot, style)` 按房子样式出小屋）；家具定义、摆放规则（落地家具看碰撞底座不重叠、门口留走道；墙饰整个挂在墙面上不重叠；地毯随便铺）、新房默认布置在 `shared/furniture.ts`，服务端校验和客户端预览用同一个 `canPlace`。地板和墙在 `interior/bake.ts` 逐像素烘焙（地板三种木色；墙面有和纸灰泥、原木板、白灰泥、石砖四种）；房间的缩放下限只按高度算，宽屏上两边露暗边、整间屋子竖着装得下；家具用 `interior` 图集，挂墙的画在人物下层，吊灯笼 `z` 设成最大、永远在人物上层。顾客（`interior/guest.ts`）只收服务端的状态和已持续时长，走位由客户端沿「门口 → 过道 → 座位」折线插值；坐下时画在凳子后面，凳子挡住腿。视野装得下整个房间就居中，否则跟人走。
- **岛屿**：地面在加载时逐像素烘焙（`island/terrain.ts`：连续场 → 地形类型 → 手调色板 + 抖动 + 草地唇边/投影）；水面是逐像素着色器（`island/water.ts`：四色分带抖动、闪光、岸边浪花、雨滴涟漪）。
- **海底**：水体背景着色器（深度渐变 + 丁达尔光束 + 海面波纹）+ AI 远景视差 + 烘焙岩石（伪法线顶光 + 分区调色板）+ 焦散（只落在受光遮罩标记的朝上岩面）+ 鱼用 `MeshPlane` 网格做尾部摆动变形。

**着色器注意事项**
- 必须兼容 **WebGL1**（GLSL ES 1.0）：不能用数组初始化、动态下标。有序抖动用算术版 `bayer4`（`fx/glsl.ts`）。
- Pixi v8 滤镜里的**纹理资源必须在构造时声明**（例如 `uLight: Texture.WHITE.source`），之后再赋值才会绑定到自己的纹理单元；否则采样器会退回 0 号单元，采到场景本身，画面上会出现放大的重影。

## 通用地图生成（`shared/world/`）

为了支持更多、更大的地图，地图改成「一行配置 + 程序生成」：

- `maps.ts`：地图注册表。一张地图 = 类型（`island` 单岛 / `archipelago` 群岛 / `continent` 大陆 / `cave` 洞穴）+ 尺寸 + 种子 + 群系。
- `defs.ts`：地形注册表（画法 + 5 档调色板 + 能否行走/耕种/是否高出一截）和群系注册表（主地面、海岸、水面是否结冰、房子样式、植被散布规则）。加新地貌只改这里。
- `gen.ts`：生成器。连续场（陆地高度、温度、湿度、河流、熔岩、海岸、到路的距离）决定地形；骨架（村子选址 → A* 修路 → 沿街排房子、院子摆设、路灯）在创建世界时一次算完；植被和地块按 32×32 的区块按需生成，只由坐标和种子决定，区块之间无缝，所以地图可以很大（1024×1024 的大陆骨架约 0.3 秒）。
- `bake.ts`：区块地面烘焙（纯函数，不依赖 Pixi），每块约 0.2~0.3 秒。
- 预览：`node tools/world-preview.mts all`（或 `<地图id> overview` / `<地图id> detail x y w h`）输出到 `art/preview/world/`，用真实烘焙和真实精灵渲染；还没有素材的新物件画成色块并列出来。

**游戏里怎么去**：在栈桥上找船长老潘 →「出航去别的地方」→ 选目的地。每张地图都有**传送石**（顶上悬浮青色水晶、夜里发光）：到达就站在第一块传送石前；每个村子的广场西北角各有一块（没有村子的地图在中间找空地放一块，洞穴叫「洞口」）。在任意一块传送石前按 E：回潮汐港、去同一张图里最近的 4 个村子、或者直接去别的地图。离传送石远了，屏幕边缘有青色箭头指向最近的一块并标出距离。在别的地图下线，重连后回到栈桥。

出航/传送由服务端批准后才切场景（`travel` → `goto`）：出发点必须在栈桥或老潘身边、或者某块传送石旁；落点就是目标传送石的站位，前后端用同一个生成器算，不会错位。

**客户端**（`src/world/`）：`WorldScene` 能渲染任意一张注册的地图。按镜头位置流式加载区块（视野外 1.5 个区块就释放），地面和水面在 Web Worker 池（`bake.worker.ts`，最多 4 个）里后台烘焙，主线程每帧最多新建一个区块的物件（约 4~10ms），实测横穿大陆没有卡顿。水面用和潮汐港同一个着色器；洞穴里环境光常暗、只靠自己的灯。

**服务端**：场景 id 是 `map:<地图id>`，同一张图上的玩家互相可见；只能从潮汐港栈桥出航，落脚点和客户端用同一个生成器算，保证一致。

**还没做的**：新地貌的精灵（雪松、仙人掌、石笋、水晶、矿石……，预览图里是色块，游戏里暂时不显示）；新地图上的种田、NPC 和采集；潮汐港本身还是老的手写地图，之后迁移到这套系统。

## 服务端（`server/main.ts`）

Node 22 原生跑 TypeScript（类型擦除）。所以 `shared/` 和 `server/` 只能写可擦除语法：不能用 enum 和构造函数参数属性，类型导入必须写 `import type`。

- 权威数据：世界时钟、农田、背包金币、鱼群模拟（20Hz，10Hz 下发）。玩家位置由客户端上报，服务端按时间做最大步长校验。
- 存档：`node:sqlite` → `server/data/world.db`（已被 .gitignore 忽略）。身份用 localStorage 里的 token，同一存档重复登录会顶掉旧连接。
- 寿司店：顾客状态机（进门 → 等菜 → 吃 → 离开）在服务端 2Hz 推进，只在营业时间、店里有人、今天的客人还没来完（存档 meta 的 `guests`）时来客；做菜校验人站在对应灶台前、食材够，扣食材后记下手上的菜；上菜校验菜对得上、够得着座位。出门或断线时手上的菜作废。
- 潜水装备：`players.gear` 一列（JSON：`{ tank, harpoon }` 等级，老存档自动补列、默认 0 级）。升级要站在小珊附近，扣金币和材料后下发 `gear` 消息；数值表是 `shared/data.ts` 里的 `TANKS / HARPOONS`。
- 复兴工程：全服进度存在 `meta` 表的 `restore` 一行（JSON：已完工几期、当前这期每项捐了多少、凑齐的日子、每位玩家的贡献分），捐赠要站在工程告示板旁边、只能捐当前这期、捐多少扣多少；每天开始时把前一天凑齐的那期记为完工并广播 `restore`。数值表是 `shared/restore.ts`。集市日的卖价加成、村民去集市的日程（`shared/schedules.ts` 的 `town.market`）、客船来了以后寿司店来客更快，都按这份进度算。
- 心事件：服务端校验好感门槛、前置事件、工程进度（`stage`）、前置剧情任务（`quest`），没看过才执行效果；小镇事件（`town`）看了后面一期就把前面几期一并记成看过。海底剧情物品（`shared/sea.ts` 的 `SEA_FINDS`）要有对应任务、背包里还没有、人在物品附近才给，没有高压气瓶下不到蓝洞底，捡不到阿海的刀。
- 完成过的任务：每日委托只留最近 150 条，剧情任务永远保留（后面的心事件要查）。
- 宅基地：`players.lot / style` 两列（老存档启动时自动补列）。上线时没有房子就分配最小的空地；住满 10 户后新玩家暂时没有房子。机器人的 token 存在 `tools/.bot-tokens.json`，反复测试不会多占地。

开发时可以在浏览器控制台调 `__tide.shot('名字')`，它会把当前画面存到 `art/preview/shots/`，用来检查美术效果。

不想碰正式存档时，可以另起一套测试环境（新存档的世界时钟从 `--start-hour` 指定的钟点开始，测餐厅时设成 16.8 左右，几秒后就开门）：

# 把事件记成看过、剧情任务记成完成（跳过前置）。改玩家存档前先断开这个玩家的连接

## 版本管理

- 项目根目录是 git 仓库（主分支 `main`）。`*.png / *.ogg / *.mp3 / *.wav / *.woff2` 由 Git LFS 管理，文本统一 LF 换行。
- **不进仓库的**：`.env`（密钥）、`server/data/`（世界存档）、`dist/`、`node_modules/`、`*.bak`（改动前的手工备份）、`art/preview/`（调试截图，可重新生成）、`art/vendor/`（下载的原始压缩包，用到的文件已在 `public/`）、`art/sprites/`。
- `art/raw/` 里的 AI 原图是真正的源文件（重新生成要花钱且结果不同），和 `art/manifest.json` 一起提交；`public/assets/` 的图集由 `build-art.cjs` 从它们生成，也一起提交，方便直接运行。
