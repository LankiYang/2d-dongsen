# 2D动森 · 开发规划

> 目标：2D 版的《集合啦！动物森友会》。2026-10-07 从潮汐港（潜水员戴夫 × 星露谷）的 `animal-crossing` 分支独立成单独的项目，两边各自发展。改动前先看这里，做完一阶段回来更新「进度」。

## 已定的方向（2026-09-30，用户选定）

| 问题 | 选择 |
|---|---|
| 画面 | 俯视、生图 + 渲染管线不变，画风往动森靠：更明亮、更圆润、更可爱，定为**粉嫩圆润版**。之后用户改定：**不要像素颗粒，换成高清平滑画风**（海底除外） |
| 界面 | 换成动森式的奶油色圆角面板、胶囊按钮、白色对话气泡 |
| 角色 | 7 位村民和玩家小人都按新画风重画（Q 版大头、豆豆眼、红脸蛋），长相特征不变 |
| 村民 | 保留现在的 7 位人类村民和他们的剧情，不换成动物 |
| 时间 | 跟现实时间同步：游戏里一天就是现实一天，季节跟着现实走 |
| 世界结构 | 潮汐港是大家共用的小镇；每个玩家另有一座自己的私人小岛，坐船来回、去朋友岛上串门 |
| 新玩法 | 图鉴和博物馆、岛屿装修和改地形、DIY 手工和采集、每人一座岛互相串门（四样都要） |

## 玩法向动森看齐（2026-10-07，用户定）

用户的话：「现在只是做了很简单的动森画风处理，我们要的是玩法上的一致」。潮汐港时期的核心循环是星露谷式的（格子农田 → 鱼枪打鱼 → 寿司店做菜卖钱 → 升级装备，体力管着每天能做多少）；动森的日常是另一套：每天在岛上转一圈收集、抓生物填图鉴、按配方做家具和工具、装修自己的岛、还房贷扩建房子、和村民来往，没有体力、没有战斗，每天能做多少靠「资源每天刷新」来限制。

| 问题 | 用户的选择 |
|---|---|
| 体力 | **去掉**。限制靠每天刷新的资源和按季节、钟点出现的生物 |
| 潜水 | **改成动森式**：下海徒手抓海洋生物，进图鉴、能捐博物馆；去掉鱼枪射击和鲨鱼。海底画面不变；岛上另加钓竿钓鱼 |
| 寿司店 | **去掉**做菜玩法。钱主要靠卖采集物、抓到的生物、作物和大头菜；寿司店的房子改成别的店铺或者装饰 |
| 先做什么 | **私人小岛 + 每日采集**；美术重画先停，玩法做出来再补画 |

| 动森玩法 | 潮汐港时期 | 做成 |
|---|---|---|
| 每日采集 | 没有 | 私人岛上每天刷新：摇树（掉树枝、水果，偶尔掉家具）、砍树得木材、敲石头出石块 / 黏土 / 铁矿、挖化石、海边捡贝壳、拔草、漂流瓶（配方） |
| 工具 | 锄头、水壶、鱼枪（买、升级） | 斧头、铲子、捕虫网、钓竿、水壶、弹弓，用材料做，会用坏 |
| 抓生物 | 下海用鱼枪打鱼 | 岸边钓鱼（鱼影、咬钩时机）、捕虫网抓虫、潜水徒手抓海洋生物；按季节、钟点、天气出现 |
| 图鉴和博物馆 | 没有 | 每种第一次抓到进图鉴；潮汐港盖博物馆，捐了以后馆里能看到 |
| DIY | 没有 | 工作台 + 配方（村民送、漂流瓶、里程兑换） |
| 装修 | 只能摆室内家具 | 家具摆到户外、铺路、种花种树，之后改地形；岛屿评价 |
| 房子 | 潮汐村宅基地 | 私人岛上自己的房子，贷款扩建，收纳跟着变大 |
| 货币 | 金币 | 铃钱 + 里程（成就和每日小目标），告示板委托改成里程任务 |
| 每周 | 周六集市 | 周日大头菜，商店收购价一天变两次；周六集市保留 |
| 种地 | 潮汐港的公共农田，格子田 | 搬到自己岛上，想种哪就种哪 |

## 世界结构：什么留在潮汐港，什么搬到私人小岛

| 放在哪 | 内容 |
|---|---|
| 潮汐港（全服共用） | 7 位村民和他们的剧情、鱼摊、种子铺、潜水店、告示板、复兴工程、周六集市、新建的博物馆、码头和那片共用的海（寿司店不再营业，房子另作他用） |
| 私人小岛（每人一座） | 自己的房子（从潮汐村的宅基地搬过来，不再受 10 户的限制）、自己的农田、采集点（树、石头、树枝、杂草、化石点、贝壳、虫子）、户外装修、改地形 |
| 来往 | 老潘的船：潮汐港 ↔ 自己的岛 ↔ 朋友的岛。私人小岛用现有的通用地图生成器按玩家 id 生成，每人不一样 |
| 串门规矩 | 访客能逛、能看、能摘水果、能聊天；挖地、改地形、搬家具、拿箱子里的东西只有岛主能做（以后可以加「好友可以帮忙」） |

潮汐村现在的 10 块宅基地：房子搬走以后，空出来的房子做成村民的家、店铺或者游客小屋（到时候再定）。

## 现实时间要跟着改的系统（2026-10-06 做完，经济和采集点除外）

时区按北京时间；季节按北半球月份（3～5 月春、6～8 月夏、9～11 月秋、12～2 月冬）。

| 系统 | 现在 | 改成 |
|---|---|---|
| 一天 | 现实 10 分钟 | 现实一天，每天早上 6 点结算 |
| 作物 | 2～5 个游戏日（20～50 分钟）成熟 | 2～5 天成熟（和动森里种花、种南瓜一样慢） |
| 体力 | 每天早上回满，出海 40 | 先改成每分钟回 1 点；之后整个去掉（玩法向动森看齐） |
| 寿司店 | 10:00–20:00 | 先改成 10:00–22:00、每天最多 24 位客人；之后整个去掉（玩法向动森看齐） |
| 村民日程、心事件时段 | 按游戏钟点 | 直接变成现实钟点，不用改代码 |
| 复兴工程 | 凑齐后第二天完工 | 现实的第二天 |
| 集市日 | 游戏里的周六 | 现实的周六 |
| 生日 | 季 + 日（夏 9 日） | 换算成现实日期（6 月 9 日） |
| 天气 | 一天 22% 的概率整天下雨 | 大约三成的日子下一阵雨（2～6 个钟点，6～22 点之间开始），雨一开始田地自动浇透，换日时预告 |
| 老世界 | | 第一次按新规则启动时把纪元定在「今天 6 点往前推 (老天数 - 1) 天」，天数接着数（meta `epochReal`） |
| 采集点（树、石头、化石） | 没有 | 每天刷新一次，和动森一样 |
| 经济 | 按 10 分钟一天算的 | 等时间和采集做完以后整体重算 |

## 画面：高清平滑画风（2026-09-30 改定）

用户看了像素版的自然物件后说「新画风下不应该有像素点了」，改成高清平滑的卡通画风：素材不再是像素画，陆地场景按屏幕分辨率渲染。海底保持原来的像素风。

- **风格常量**：`tools/style.cjs` 的 `HD_CORE / HD_LAND / HD_ICON / HD_SCENE / HD_CHAR`。平滑矢量感的造型、柔和的赛璐璐阴影、整圈闭合的深色描边（抠图靠它）。拿像素样图当参考图时只借造型和配色（`buildPrompt` 对 HD_ 风格换了一句参考图说明）。
- **素材构建**：`art/manifest.json` 里名字以 `_hd` 结尾的图集走 `tools/hd.cjs`：白底软边抠图（沿描边外侧估 alpha、颜色取描边色，不留白边）→ 切块 → 按 `heights`（游戏里的高度，美术像素）面积平均缩小 → 4 倍密度打包（json 的 `meta.scale = 4`）。精灵在世界里的尺寸和像素版一样，碰撞、摆放都不用改。`holes` 填最小面积，把叶子缝里成片的白底也抠掉（有白色高光的素材别开）。
- **运行时**：`src/acstyle.ts` 的 `HD`（= 新画风）。`PixelView` 的高清模式：世界容器整体放大、按屏幕分辨率渲染，倍率不取整（缩放一档 1.2 倍）；角色位置不再取整（`snap`）；高清图集同名覆盖像素版（`core/assets.ts` 的 `HD_ATLASES`，线性过滤 + mipmap）；影子是软边椭圆；摆动改成上段以分界线为轴连续斜切。
- **地面**：`island/ground.ts` 的地面着色器。陆地、小路、沙滩三个连续场存进一张低分辨率的场纹理，屏幕上逐像素按阈值上色、抗锯齿；草地唇边、投影、高光、草簇、沙粒、卵石都是按世界坐标画的矢量小笔触。栈桥是单独画的 4 倍密度贴图（`terrain.ts` 的 `dockHD`）。
- **水面**：`island/water.ts` 的 `fragmentHD`：色带柔和过渡不抖动，离岸距离线性插值所以浪花是平滑曲线，闪光和雨圈是矢量笔触。
- **还是像素的**：没重画的素材（建筑、户外摆设、角色、图标、家具、作物）照旧显示，放大倍率不再是整数，会有点不均匀，重画后自然消失；通用地图（`src/world`，私人小岛以后也用它）的地面还是逐像素烘焙的，做私人小岛时改成场纹理 + 地面着色器；室内的地板墙面同理（`interior/bake.ts`）；耕地纹理。
- 角色锚点：`art/raw/hd_cast.png`（玩家 + 7 位村民的高清设定图），画角色时都拿它当参考图。行走帧的侧面单独生成（纯侧面、一律朝右），不和正面背面放在一张图里，不然朝向会乱。
- 生图的规矩：白底上不要画白色的主体（白花瓣会被当成背景抠掉）；花草比主角矮一截（主角 34 像素高，花 20 像素左右），不然站在花后面整个人被挡住；树换图后要重量 `src/fx/sway.ts` 的 `SPLIT`（切在树冠下沿）；建筑正立面。
- 样图页：开着分支的客户端（5192）时访问 `/art/preview/style-samples.html`（本地文件，不进仓库）。开关：网址加 `?oldstyle` 看星露谷方向的旧画面（像素渲染、旧配色、旧界面）。
- 着色器要写 `#version 300 es` 开头：PixiJS 只在看到这一行时按 GLSL 3.0 编译，否则 `fwidth` 用不了。分支里算导数（`fwidth`）不可靠，线段和矩形的抗锯齿宽度直接用 `0.75 / uScale`（屏幕 1 像素在世界里的宽度）。

## 画风往动森靠（像素版，已停用，留作记录）

动森的观感：明亮饱和的颜色、柔和的阴影、圆滚滚的造型、大量绿色和花、干净的界面（圆角白底气泡、胶囊按钮）。

- 风格常量：`tools/style.cjs` 的 `AC_CORE / AC_LAND / AC_ICON / AC_SCENE / AC_CHAR`（粉嫩圆润版，角色是 Q 版大头）。已停用，新素材用 `HD_*`。
- 角色锚点：`art/raw/ac_cast.png`（玩家 + 7 位村民的设定图），画角色时都拿它当参考图。
- 样图页：开着分支的客户端（5192）时访问 `/art/preview/style-samples.html`（本地文件，不进仓库）。
- 开关：分支默认新画风，网址加 `?oldstyle` 看旧的（`src/acstyle.ts`）。还没重做的物件先用样图顶上（`acKind`），全部重做完就删掉这个开关。
- 生图踩过的坑：白色的花（白波斯菊）在白底上抠不干净，花瓣会被当成背景吃掉，生图时要求「不要白色花瓣」；花丛茎叶之间夹着的白底要在清单里用 `holes` 清掉；花草比主角矮一截（主角 34 像素高，花 20 像素左右），不然站在花后面整个人被挡住。树换图后要重量 `src/fx/sway.ts` 的 `SPLIT`（切在树冠下沿）。
- 像素网格、整数放大、正立面这些规矩不变。行走帧的侧面单独生成（纯侧面、一律朝右），不和正面背面放在一张图里，不然朝向会乱。
